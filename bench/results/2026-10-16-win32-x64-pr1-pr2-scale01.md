Migration means EXPECTED_DIFFERENCE: the complete JSON contract changed, so no
speedup is computed. The allowlist still verifies unchanged counts, ordered
items, exact hex cursor/total additions, or UTF-8-safe prefixes with the correct
original byte count. A count/content drift remains a mismatch. Rejection means
both workers returned OUTPUT_LIMIT for the 33 MiB inspect; R is rejection

neither comparison had a timeout, transport error or unexpected worker error.

## Resource and contract evidence

- PR 1 deterministic resource assertions remain covered: excluded names do no
  child metadata/subtree work; known oversize handles read zero body bytes;
  growth reads at most MAX+1; summary/count retain no hit positions; content
  constructs only its requested page; globs parse once and split paths once;
  a 32-byte hex window reads 32 bytes. Release builds omit test counters.
- PR 2 visits root/enumerated entries, including exclusions; checks chunk reads,
  matching, traversal and result construction against independent budgets.
  A stopped current file contributes neither unvalidated text nor matching
  counts. Soft deadline/read/visit stops cannot claim exact full-tree absence.
- Host deadlines cover invocation through managed-range exit. Native cooperative
  deadlines reserve up to 1000 ms for settlement; provider termination has its
  own 1000 ms grace. This is not an absolute wall-clock guarantee for OS calls.
  Real managed subprocess tests verify hard timeout, subsequent successful
  query, external cancellation, unload and actual range exit. Captured success
  JSON is rejected after cancellation. Interrupted replace retains unknown
  effects; read interruption has no write effects.
- The benchmark's 1 MiB line output fell from 1,048,877 to 4,560 native JSON bytes
  with explicit textTruncated/textBytes. Real-worker tests use escaped Chinese,
  quotes, backslashes and tabs, and verify native JSON, final value and serialized
  text-render array all fit their configured budgets. Paging advances.
- Results distinguish scanComplete, pageComplete and totalExact; early scans
  expose lower bounds without fake exact total/omitted. Budget-limited hex pages
  report the actual row progress and limiting line/output budget; EOF has no
  spurious pageLimit reason. The real DSH registry validates every definition.
- Text inspect nextOffset now uses the next one-based input line, fixing a
  reproduced repeat-page bug. Consumers that manually added one must stop doing
  so. Hex retains zero-based 16-byte rows; grep/glob retain zero-based item units.
  Pagination rescans the scope and is neither a snapshot nor a resume cursor.

Defaults, units and ranges are documented in
[configuration reference](../../docs/configuration-reference.md#filebudgets-defaults-and-ranges);
the caller-facing migration is in
[component reference](../../docs/component-reference.md#results-and-errors) and
[changelog](../../CHANGELOG.md).
